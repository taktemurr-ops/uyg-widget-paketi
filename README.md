# Widget Paketi · Widget Pack

Saat, tarih, geri sayım ve not panosu · A board of clock, date, countdown and notes

Kişiselleştirme ailesinin uygulaması. Çevrimdışı çalışır; telefon, tablet ve web.
Gerçek uygulama ortak motordadır: [kisisel-motoru](https://github.com/taktemurr-ops/kisisel-motoru); çatı ve
reklam/satın alma/gizlilik: [studio-core](https://github.com/taktemurr-ops/studio-core) (`lib/apps`).
Merkez uygulama: [merkez-kisisellestirme](https://github.com/taktemurr-ops/merkez-kisisellestirme).

Görseller ve sesler kodla üretilir; marka, logo veya üçüncü taraf içerik yoktur. Uygulama izin istemez.
